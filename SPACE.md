# Inside GLiNER2.5

Watch a real information-extraction model read a sentence, stage by stage and layer by layer: entities, classification, relations, structured records and span attributes, all from one pass of [fastino/gliner2.5-multi-v1](https://huggingface.co/fastino/gliner2.5-multi-v1).

**[Source code on GitHub](https://github.com/polodealvarado/gliner2-visualizer)** · **[Run it locally](https://github.com/polodealvarado/gliner2-visualizer#run-it-locally)**

This Space shows precomputed examples from the real model. It does not run the model on a server.
Choose an example for each task. Sentences, schemas and threshold are fixed in this online demo.
To analyze your own text, run the project locally using the instructions above.

GLiNER2 and the GLiNER2.5 checkpoints are by [Fastino AI](https://fastino.ai) ([paper](https://arxiv.org/abs/2507.18546)).
Made by [@polodealvarado](https://huggingface.co/polodealvarado). Independent project, not affiliated with Fastino.
